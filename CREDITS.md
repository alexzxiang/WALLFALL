# WALLFALL — Asset Credits

WALLFALL is released free of charge. Its art, audio, and font assets come from the creators
listed below and remain the property of their respective creators. Thank you for making these
resources available to independent game developers.

This list covers only the third-party assets included in the current public WebGL build.
WALLFALL distributes them as part of the compiled game, not as reusable source files. The raw
packs and the generated `Assets/Resources/Wallfall/itchio/` cache are local-only and ignored by
Git.

The current asset set is intended only for WALLFALL's strictly free, non-commercial release. A
